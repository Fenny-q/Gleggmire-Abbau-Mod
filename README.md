# Gleggmire Abbau Mod

Eine kleine Minecraft-Mod mit einem etwas anderen Approach.

Sobald du einen Block abbaust, erscheint ein zufälliges Bild von Gleggmire. Absolut unnötig, aber finde ich.

## Funktionen

- Zufälliges Bild bei jedem neuen Block
- Bilder auf allen Blockseiten
- Normale Abbaurisse bleiben sichtbar
- Komplett clientseitig
- Kein Resource Pack nötig

## Installation

1. Lade die `.jar` unter [Releases](https://github.com/Fenny-q/Gleggmire-Abbau-Mod/releases) herunter.
2. Installiere Fabric und Fabric API.
3. Packe die Datei in deinen `mods`-Ordner.
4. Starte Minecraft.

## Voraussetzungen

- Minecraft 1.21.11
- Fabric Loader
- Fabric API

## Sonstiges

Die Mod ist komplett clientseitig. Andere Spieler sehen die Bilder nur, wenn sie die Mod ebenfalls installiert haben.

Einigermaßen sinnvoll? Nein.

Einigersarcel? Auf jeden Fall.

Wer sich darüber aufbauscht, muss erstmal elaborieren, warum.

## Letzte Worte

Diese Mod hat absolut keinen Sinn, aber einen stabilen Approach.
